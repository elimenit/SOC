# SOC (Security Operations Center)
Mi Entrenamiento para ser un SOC Analyst, Veremos muchas cosas 💙

## Que es un SOC 
Un SOC monitoriza, detecta, analiza y responde a incidentes criticos en tiempo real para proteger activos criticos.

## Tipos de SOC

- ***SOC Interno***

- ***SOC Hibrido***

- ***SOC Externalizado***

## Alcanze de un SOC

- ***Activos criticos***: El alcanze del SOC debe incluir insfraestructura, endpoints, aplicaciones y entornos en la nube para la proteccion integral.

- ***Amenazas Principales***: Son ataques externos y internos.
    - *Externos*: Malware y campañas APT

- ***Proteccion de datos y Servicios***: El alcanze del SOC debe proteger datos sensibles, sistemas criticos y servicios esenciales para el negocio.

- ***Adaptacion Geografica***: Adaptarse al *cumplimiento normativo*(Normativas locales e internacionales para protege datos sensibles) y *Politicas Coherentes* (Definir un alcance claro).

## Perfiles 
- ***SOC Manager***: Dirige la estrategia y coordinatodas las actividades del SOC para garantizar la eficiacia.

- ***Analista de Seguridad***: Los Analistas de Seguridad 1, 2 y 3 monitorean incidentes y responden rapidamente para mitigar amenazas.

- ***Arquitecto de Seguridad***: Diseña y Mantiene la insfraestructura tecnologica para proteger la organizacion.

- ***Equipo CTI***: El Equipo de Ciber Threat Intelligence analiza y anticipa amenazas emergentes para mejorar la defensa.

## Skills y Certificaciones

- ***Habilidades Tecnicas Esenciales***: Los perfiles SOC necesitan Analisis Forense, Gestion de Incidentes, Scripting, y manejos de herramientas SIEM y SOAR.

- ***Certificaciones Valoradas***: CISSP, CEH, y GCIA son altamenes valoradas.

- ***Formacion Continua***: Esta claro adaptarse al cambio para enfrentarse a nuevas amenzas.
